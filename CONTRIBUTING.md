# Contributing to DragonCommand

Thank you for your interest in DragonCommand.

## Current Status

DragonCommand is in **active early development** and is **not yet open for external contributions.** The codebase is proprietary and the architecture is still being finalized.

This will change. We plan to open specific parts of DragonCommand to community contribution in the future — particularly documentation, translations, LSL bridge scripts, and community-built Add-On modules.

## How to Help Right Now

Even without open contributions, there are meaningful ways to support the project:

### ⭐ Star and Watch this Repository
Following development progress is the single most helpful thing you can do right now. It signals community interest and helps shape prioritization.

### 💬 Join the Discussion
Have an idea, a use case, or feedback on the roadmap? Open a [Discussion](https://github.com/mteedev/dragoncommand-platform/discussions). Grid operator perspectives — especially from operators of large, production grids — directly influence what gets built next.

### 🐛 Report Issues with the Live Demo
If you find something broken or unexpected at [www.msaxiom.com](https://www.msaxiom.com) or [panel.msaxiom.com](https://panel.msaxiom.com), open an [Issue](https://github.com/mteedev/dragoncommand-platform/issues) with a description of what you observed.

### 🗺️ Review the Roadmap
Read [ROADMAP.md](ROADMAP.md) and let us know in Discussions if something important to your grid is missing, misaligned, or should be prioritized differently.

### 🌐 Spread the Word
If you operate an OpenSimulator grid and think DragonCommand would help your community, tell other grid operators. The OpenSim ecosystem is small and word-of-mouth matters.

## What's Coming

When contributions open, the first areas will likely include:

- **Documentation** — Installation guides, configuration reference, API docs
- **Translations** — i18n support for non-English grid communities
- **LSL Scripts** — In-world HUD and vendor scripts for the grid bridge
- **Add-On Modules** — Community-built extensions via the plugin SDK (Phase 5)
- **Themes** — Custom grid branding presets

We'll publish detailed contributing guidelines, a code of conduct, and a contributor license agreement when that time comes.

---

## For Grid Operators Interested in Early Access

If you operate a production OpenSimulator grid and want to be considered for early access testing, open a Discussion and tell us about your grid — size, architecture (standalone vs. grid mode, Robust setup), and what you'd most want DragonCommand to solve for you.
